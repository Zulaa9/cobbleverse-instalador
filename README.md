# Instalador de Cobbleverse (servidor privado entre amigos)

Instalador del cliente para jugar en nuestro servidor privado de Cobbleverse
(Minecraft Java 1.21.1 + Fabric + Cobblemon). Solo sirve para entrar a ese servidor: la lista blanca y el inicio de
sesión del servidor impiden entrar a quien no esté invitado.

## Descarga

Ve a **[Releases](../../releases/latest)** y descarga `Cobbleverse-1.5.7-amigos.zip` (y, si quieres comprobarlo,
`Cobbleverse-1.5.7-amigos.zip.sha256`).

## Instalación

1. Descomprime el zip.
2. **Windows:** ejecuta `Cobbleverse-Setup-1.5.7.exe`. **Linux:** sigue `LEEME-LINUX.md`.
3. Elige tu launcher (oficial, TLauncher o Prism). Si ya tenías una versión anterior, elige **Actualizar**: se conservan
   tus mundos, capturas, servidores, opciones y la caché de Distant Horizons.
4. Acepta la configuración recomendada (memoria según tu RAM; con 8 GB, modo Ligero y cierra otros programas).
5. Pulsa **Jugar** en el instalador, o abre tu launcher y entra con el perfil **Cobbleverse** (en TLauncher, «Oficial Cobbleverse-Servidor», ya elegido y el primero de la lista). **Cierra TLauncher antes de instalar.**
6. La primera vez, sigue «Primer acceso» de `LEEME-JUGADORES.txt` (contraseña del servidor).

Toda la información para jugadores está dentro del zip: `LEEME-JUGADORES.txt`, `GUIA-JUGADORES.md` y `CAMBIOS-1.5.7.txt`.
